# SmartSchedule 5.1 发布说明

版本：5.1（versionCode 51）· 基于 5.0 源码升级 · 沿用 4.0 正式签名

## 本次更新

### 外观
- 原「靛蓝」实际呈现偏 M3 默认紫，改为明确的「湛蓝」`#006BDF`，并默认使用忠实（fidelity）配色保住蓝色相；老用户升级时自动迁移一次。
- 修复深色模式玻璃顶栏、设置分组标题等文字发黑不可读的问题（玻璃容器现在正确下发 `LocalContentColor`）。
- 提高深色玻璃底色遮罩；AMOLED 纯黑模式关闭背景光斑。
- 新增更丰富的 M3 动效：按压回弹、底栏触感反馈、单双周切换动画、作业列表重排动画；新增「减少动态效果」开关，全部动效遵循该设置。

### 首次使用与合规
- 首次进入必须分别阅读《免责条款》《用户须知》，每篇都强制滚动到文末并主动勾选才能继续；同意记录独立存储、不进备份。
- 设置新增「条款与权限」：可随时重读两份文档，并查看权限说明（联网获取实时天气/分享码/检查更新、大致位置、通知、闹钟、安装）。

### 定位
- 新增「定位当前城市」：仅按需请求 `ACCESS_COARSE_LOCATION`（大致位置，无后台定位、无 GPS）。
- 城市识别由设备直连 BigDataCloud 免费接口完成（依其政策不经服务器代理），坐标降精度到约 2 km，识别结果需用户确认后才会使用。
- 定位缓存独立存储、排除在备份之外；手动改城市即清除定位数据。

### 网站与服务
- 全新官网：主题/深浅模式/液态玻璃强度在线预览、交互式单双周跨周演示、2.58 MB 小体积卖点、完整深浅色适配与减少动态支持。
- 分享码服务升级 2.1：64 KB 体积上限、严格数据校验、按 IP 限流、原子取号、PHP-guard 存储目录保护；完全兼容读取旧分享码，旧数据零迁移。
- 服务端已适配 `open_basedir` 受限主机（自动回退 `fxm/private`），响应保证纯 JSON。
