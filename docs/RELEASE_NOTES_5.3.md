# SmartSchedule 5.3 发布说明

版本：5.3（versionCode 53）· 基于 5.2 · 沿用 4.0 正式签名，可直接覆盖升级。

## 本次更新

### AI 快速导入课表 / 作业
史上最简单的配置方法：拍一张课表或作业，交给 AI 助手识别，粘贴回来就填好了。不用申请 API、不用填密钥、不用选模型。

1. 在智能课表里点「复制提示词」。提示词就是输出规则，带着你已有的课程名、每天几节（课表）或今天的日期（作业）。
2. 打开 DeepSeek、豆包、Kimi 或元宝（没装 App 会打开网页版），上传照片，粘贴提示词发送。
3. 复制 AI 的回复。
4. 回到智能课表粘贴，先预览，确认后导入；导入后几秒内可以撤销。

- 入口：课表页右上角 ✦、作业页「AI 导入」、设置 › 备份、恢复与分享码、首次引导（课表来源默认推荐这一项）。
- 课表：能识别单双周不同的课（包括格子里写「物理(单)/化学(双)」）、晨读、上下课时间。可以更新当前课表（只替换识别到的那几天），也可以新建一张；上下课时间可选是否一起导入。
- 作业：「明天」「周五前」「下周一」会换算成日期，没写截止的按下一个上学日。逐条勾选，已有的重复作业默认不勾。
- AI 的回复不规整也能读：夹着解释文字、照抄了注释、多了逗号、用了中文引号都没关系。识别不了会说明原因。
- 导入页有一段四步引导动画；开启「减少动态效果」时显示静止画面。
- 从 AI 助手切回来时，如果剪贴板里正好是 AI 的回复，会自动填进来（只在本页复制过提示词之后才读剪贴板）。部分系统限制读取剪贴板时，点「从剪贴板粘贴」即可。

## 隐私
- 照片和提示词由你自己发给所选的 AI 助手，智能课表不上传任何内容，也不接入任何 AI 服务。
- 新增对 4 个 AI 助手包名的可见性声明（`<queries>`），只用于判断是否已安装、直接打开。

## 升级
- 沿用 4.0 正式签名，可直接覆盖安装，数据保留。建议升级前在「备份、恢复与分享码」导出备份。
