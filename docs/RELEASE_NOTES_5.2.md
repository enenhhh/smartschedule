# SmartSchedule 5.2 发布说明

版本：5.2（versionCode 52）· 基于 5.1 · 沿用 4.0 正式签名，可直接覆盖升级。

## 本次更新

### 更新方式
- 默认从 GitHub Release 检查更新和下载安装包；在「关于与更新 → 更新源」可手动切到自建服务器。GitHub 连不上时自动回退到服务器。
- 更新说明可带 `sha256:`，下载完成后校验安装包，不一致就丢弃。
- 升级后更新源会回到默认的 GitHub（存档键改为 `update_source_v2`）。

### 外观
- 毛玻璃更明显：顶栏 / 底栏遮罩更透，模糊半径更大，背景色块更鲜艳。
- 关闭「液态折射」或系统低于 Android 13 时使用毛玻璃；Android 12 也能用真实背景模糊。Android 11 及以下无法实时模糊，使用半透明遮罩。
- 对话框和底部面板改用半透明面板，保证文字清晰。

### 修复
- 应用被保活多天后，首页和课表仍显示打开当天的课表。现在回到前台、日期 / 时间 / 时区变化、亮屏解锁时都会刷新，界面显示期间每 15 秒也会校对一次。
- 课表页的单双周预览会在跨周时自动翻转。
